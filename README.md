# JECRC CSE Portfolio

Create a professional and modern personal portfolio website for a first-year B.Tech Computer Science Engineering student at JECRC University, Jaipur.

Include sections for Home, About Me, Education, Skills, Projects, Certifications/Achievements, Contact, GitHub and LinkedIn.

Use a clean modern design, responsive layout, smooth navigation and professional animations.

Keep the content suitable for a first-year CSE student. Use placeholders wherever personal information is missing
